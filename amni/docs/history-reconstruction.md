# About the initial Git history

The initial AMNI history was reconstructed on November 18, 2026, from an existing
frontend prototype and project scaffold. Its October 30–November 18 commit dates
are assigned milestone labels, not recovered records of daily activity.

The commits separate actual source changes into configuration, interface,
workflow, asset, scaffold, and documentation milestones. Every reconstructed
commit includes this context in its body.

At the project owner’s request, the initial commits were later normalized to
place their project files under `amni/` from the start. This removes the separate
folder-layout commit while preserving each original source snapshot, commit
message, author, and date. The commit hashes change as a result. A local backup
of the earlier history is retained.

The backend and infrastructure milestones introduce placeholders, not working
FastAPI, database, Docker, or AWS services. See the main README for current scope
